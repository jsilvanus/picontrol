# picontrol

UI housing for pimatrix, pivoice and piprogram. Controls cameras, the video mixer, Pi inputs and outputs, piprogram and pivoice.

Status: phase A. The browser UI from `jsilvanus/pimatrix` (`packages/web`) is copied into `ui/`. Multiview (`multiview-html.ts`, still in pimatrix) moves here later. Types will come from each service's OpenAPI. Not yet built against this location.
